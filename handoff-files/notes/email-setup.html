Account Email Setup

Paste these into Supabase once, and every confirmation, password reset and email-change message goes out with the Shiur Daled Mivtzoim letterhead.

How to paste each one

  1. Open your Supabase project and go to Authentication → Emails (on some screens it’s called Email Templates).
  2. Pick the template named on the card below, like Confirm sign up.
  3. Tap Copy subject here, then paste it into the Subject box there.
  4. Tap Copy email code here. In Supabase, click into the Message body box (the Source tab if you see one), select everything in it, delete it, and paste.
  5. Click Save. The Preview tab in Supabase shows the finished look.

The code looks like gibberish in the box. That’s normal: it’s the instructions for the design, and the email itself comes out looking like the preview.

One more setting

In Authentication → Emails → SMTP Settings, set Sender name to Shiur Daled Mivtzoim and click Save, so inboxes show the site’s name instead of the Gmail address.
